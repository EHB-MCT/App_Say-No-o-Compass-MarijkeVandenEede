# Say-No-o-Compass-App
Say No(o) Compass - Artificiële Intelligentie

## Description

Say No(o) Compass is an AI-powered web application that helps users reflect on situations where they struggle to say "yes" or "no".

The application guides users through several reflection steps and generates personalized advice using the OpenAI API.

---

## Features

- User registration
- User login
- Reflection questionnaire
- AI-generated reflection
- MongoDB user storage
- OpenAI integration

---

## Installation

Clone the repository.

```bash
git clone <repository-url>
```

Install the dependencies.

```bash
npm install
```

Create a `.env` file containing:

```text
OPENAI_API_KEY=your_api_key
MONGODB_URI=your_connection_string
PORT=3000
```

Start the backend.

```bash
node server.js
```

Open the frontend using Live Server.
